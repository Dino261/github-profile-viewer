About This App

GitHub Profile Viewer is a simple web application that allows users to search for and view GitHub public profiles. This is a basic student project demonstrating client-side scripting skills.

Features

  • Search for GitHub public usernames
  • View profile information
  • Smooth animations
  • Responsive design
  • Clean and modern interface
  • Easy to use navigation
